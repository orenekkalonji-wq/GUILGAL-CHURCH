Cité Évangélique Guilgal
​Bienvenue sur le dépôt officiel du projet Cité Évangélique Guilgal.  
​📌 À propos du projet
​Ce projet a pour objectif de concevoir et de structurer la vitrine numérique (site web) de la Cité Évangélique Guilgal, offrant un espace d'information et de partage pour la communauté.
​📁 Structure du projet
​Le dépôt contient actuellement les éléments suivants :
​index.html : La page principale du site web.
​README.md : La documentation et la présentation du projet.
​🚀 Utilisation
​Pour visualiser le projet en local :
​Téléchargez ou clonez le dépôt.
​Ouvrez le fichier index.html dans votre navigateur web..md
